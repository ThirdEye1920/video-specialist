# Brand Card

Fill once. Paste at the start of any editing session. Everything the Edit Sheet writes —
hooks, captions, on-screen text, CTA — is drawn from this card.

Leave a field blank if you don't know it; the skill will use a neutral default and tell you.

```
BRAND CARD — v1

Brand / creator name:
Handle(s):

Who it's for (one line):
  e.g. "Busy people who want to cook one good meal a day without a recipe app."

Tone in 3 words:
  e.g. warm · direct · unfussy

Say this:
  (phrases, words, framings you always use)

Never say this:
  (words, claims, clichés you avoid — e.g. "game-changer", "hack", medical claims)

Caption style:
  sentence case / ALL CAPS / mixed  ·  emoji: yes / no  ·  punctuation: minimal / full

Colours (hex):
  primary:        secondary:        text on dark:        text on light:

Font (if known):
  captions:        headlines:

Default CTA:
  e.g. "Follow for one recipe a day"  /  "Link in bio"  /  "Comment 'GUIDE'"

Logo / lower-third rule:
  where (corner / lower-third) · when (first 2s / last 3s / throughout) · how long

Music / mood note (optional):
  e.g. "lo-fi, no vocals, under the voice"

Anything the editor must never do:
  e.g. "no jump-zoom on my face", "never crop the product out of frame"
```

## Fallbacks for blank fields

The skill uses these when a field is empty, and flags each one ✘ in the consistency check
until you confirm it:

| Blank field | Fallback |
|---|---|
| Tone | neutral · clear · friendly |
| Caption style | sentence case, no emoji, minimal punctuation |
| Colours | white text with a dark drop-shadow on any footage; no coloured chips |
| Headline font | same as caption font; if both blank, the editor's default bold sans |
| Text on light / on dark | pick by the footage's brightness at that beat; state which |
| Default CTA | "Save this" (Reels / TikTok / Shorts) · "Follow for more" (LinkedIn / X) |
| Logo / lower-third rule | handle plate, last 3 seconds, inside the platform safe zone |
| Music | none specified — editor's choice, kept under the voice |
